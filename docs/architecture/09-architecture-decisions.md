# 9. Architecture decisions

The decision records live in [`../adr/`](../adr/README.md), one file per decision. That folder's README is the index and explains the rules for adding and superseding a record.

A decision record is for a real choice between named alternatives. A rule that always holds belongs in [section 2](02-constraints.md), and a model that spans several parts belongs in [section 8](08-crosscutting-concepts.md).
